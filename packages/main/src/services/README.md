# Main 进程服务层

按业务领域分目录，避免单文件夹堆叠。

| 目录        | 职责                                                 |
| ----------- | ---------------------------------------------------- |
| `app/`      | 应用基础设施：路径、日志、内置资源定位、数据目录引导 |
| `settings/` | 全局应用设置读写                                     |
| `profile/`  | 脱敏方案（profile）持久化                            |
| `task/`     | 脱敏/还原任务目录与历史索引                          |
| `crypto/`   | 映射加解密与哈希                                     |
| `docx/`     | Word 文档脱敏、预览、还原与命中算法                  |
| `ai/`       | 本地模型下载、清单、llama 运行时与敏感实体识别       |

跨目录依赖：下层（`crypto`、`app`）不依赖业务域；`docx` / `ai` 可依赖 `app`、`task`、`crypto` 等。
