# DocCipher

DocCipher 是一个基于 Electron、React、Vite 和 TypeScript 的离线 Word `docx` 脱敏客户端。

## 开发

```bash
pnpm install
pnpm dev
```

## 校验

```bash
pnpm typecheck
pnpm build
```

## 打包

```bash
pnpm compile
```
