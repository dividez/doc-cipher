# DocCipher 产品设计 v0.3

## 产品定位

DocCipher 是一个完全离线的 Word `docx` 脱敏与还原桌面客户端。

它不是 Word 编辑器，也不是多人协作文档工具。产品核心是帮助用户在本地完成：

```txt
选择 docx -> 预览并确认敏感内容 -> 执行脱敏 -> 生成 masked docx + restore.enc
masked docx + restore.enc -> 本地还原
```

核心价值：

- 原文不出本机
- 脱敏可重复、可还原
- 不依赖云端服务
- 支持按业务场景维护脱敏方案
- 支持用户划词补充方案关键词

能力边界详见 [capability-guide.md](capability-guide.md)。

## 目标用户

主要用户是需要处理合同、制度、标书、审计材料、交付材料的业务或运营人员。

典型用户不一定理解正则或 OOXML，但能判断文档中哪些词需要脱敏。因此 UI 应优先支持：

- 选择文件
- 阅读预览
- 划词标注
- 选择脱敏方案
- 执行脱敏
- 找到输出文件

高级正则、JSON 配置、日志等能力应保留，但不作为主要路径。

## 核心概念

### 默认规则模板

默认规则模板是新建脱敏方案时的基础规则来源，存放在设置中。

它适合存放通用规则，例如：

- 手机号、身份证号、邮箱、银行账号（正则）
- 通用关键词（规则 id：`keywords`，即**系统关键词**）

修改默认规则模板只影响未来新建方案，不应悄悄覆盖已经保存的方案。

### 脱敏方案

脱敏方案是面向业务场景的一组规则配置（`MaskProfile`）。

一个方案包含完整 `settings`，其中方案专属关键词使用规则 id：`profile_keywords`（**方案关键词**）。

### 应用级开关

在设置页可全局控制：

- **正则规则**：是否应用模板中的 regex 规则
- **系统关键词**：是否应用模板中 `keywords` 规则
- **默认输出目录**

脱敏与命中预估均尊重上述开关。

### 本次手动标注

只属于当前打开的 docx，使用 part、段落序号与 offset 精确定位。可跨段落划词（`segments`）。

保存方案时，划词文本合并进方案关键词，并清空本次手动列表。

## 信息架构（当前实现）

```txt
工作台
├── 选择 docx / 拖入
├── 最近任务
└── 任务历史（本地索引）

脱敏
├── 左侧：文档预览
│   ├── 划词、右键菜单、手动高亮
│   ├── 规则命中高亮（切换方案 / 开文档后自动刷新）
│   └── Ctrl/Cmd+F 搜索
├── 右侧：方案、手动标注、规则摘要、密码、执行
│   └── 命中详情：弹窗（不占右侧栏）
├── 命中预估按钮 +「已预估 N 处」链接
└── 方案管理入口

还原
├── masked docx + restore.enc + 密码
└── 成功后清空表单（保留输出目录）

方案管理
├── 导入 / 导出 / 复制
└── 方案关键词编辑（与系统关键词区分说明）

设置
├── 快捷开关（正则、系统关键词、默认输出目录）
├── 规则列表
└── 高级 JSON
```

## 脱敏主流程

1. 用户选择 docx，应用加载文本预览。
2. 选择脱敏方案（或临时方案）；规则摘要区分正则、系统词、方案词。
3. 预览中划词加入本次手动标注；可选保存进方案关键词。
4. 应用 silent 刷新命中预估，左侧显示规则命中高亮（不自动弹窗）。
5. 用户点击「命中预估」可刷新并打开弹窗查看分组统计与样例。
6. 输入还原密码，执行脱敏，输出 masked docx、restore.enc、manifest、日志。

## 命中预览（脱敏前）

- IPC：`previewDocxMatches`，不修改源文件。
- 返回段落级 `hits[]`（含 `kind`：regex / system_keyword / profile_keyword / manual）。
- 左侧预览：`docx-rule-hit` 高亮；系统词与方案词可用不同底色。
- 详情：**居中弹窗**，按类型分组，展示未命中规则、样例与「在预览中定位」。
- 切换方案或变更规则/手动项后 debounce 自动 silent 刷新。

## 预览内搜索

- 工具栏搜索条：输入、上一条/下一条、计数、关闭。
- `Ctrl+F` / `Cmd+F` 聚焦；`Enter` / `Shift+Enter` 跳转；`Esc` 关闭。
- 样式：`docx-search-hit` / `docx-search-current`，与手动、规则高亮区分。

## 结构标签

预览块仅在**非正文区域**或**表格内**显示结构芯片（页眉、页脚、脚注、尾注、批注、表格内）。

纯正文段落**不显示「正文」标签**。

## 关键词：系统 vs 方案

| 类型       | 规则 ID            | 配置            | 开关                     |
| ---------- | ------------------ | --------------- | ------------------------ |
| 系统关键词 | `keywords`         | 设置 → 默认模板 | `enable_system_keywords` |
| 方案关键词 | `profile_keywords` | 当前脱敏方案    | 随方案启用               |

脱敏页规则摘要、命中弹窗、方案编辑页均区分两类关键词。

## 划词交互

- 左键划词 →「加入脱敏」→ 高亮 → 进入手动列表
- 右键：加入脱敏、复制、清空当前选择
- 工具栏「清空标注」：清空当前文档全部手动项

## 视觉与布局

```txt
左侧：文档预览（独立滚动）
右侧：方案、手动标注、规则 chips、密码、执行（保持紧凑）
弹窗：命中详情（最大高度约 70vh）
```

## 非目标（当前）

- OCR、LLM 语义审核
- PDF / 非 docx 格式
